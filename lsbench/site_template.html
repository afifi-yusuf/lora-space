LoRA-Space Bench

An editor model gets a frozen model and one sentence from a user, such as “make this model better at math”. It must find what goes wrong and write a LoRA adapter (ΔW = B·A, rank ≤ 8) without gradients. We score the edit on held-out problems and count what it cost.
